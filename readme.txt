My final project will be a rhythm game called “Tap Tunes.” The project will be a clone of the popular game “OSU.”
“Tap Tunes” will be a rhythm game where the players goal is to get as high of a score as possible by timing their inputs with the rhythm of the song of the map. The player can interact with multiple game components. There are tap circles, which the player needs to try and click on beat. There will be sliders, which the player needs to hold and move their mouse within a given bound for a number of beats. Then there will be spinners, the players’ main goal of the spinner is to spin it as many times as possible in a certain amount of time. The score will be calculated based on the timing of the user input for each component and multiplied by the players’ combo. The player can achieve even higher scores by activating debuffs. These debuffs will make the game more difficult by speeding up the songs, limiting the players’ field of view etc. There will be multiple levels, each with their own songs.
This game will cover the following topics:
	Game Loop and Architecture
	Action and Interaction
	Perspective and Views
	FSM’s
	Motion and Physics
	Particle Systems
